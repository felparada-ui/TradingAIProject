# TradingAIProject

## Descripcion
Sistema de trading con CrewAI para analisis de datos historicos de MT5.

## Estructura
- `src/trading_bot_crew/` - Codigo principal
- `data/` - Datos historicos y resultados
- `notebooks/` - Analisis exploratorio

## Como usar
1. Abrir en VS Code con Dev Container
2. Configurar API key en `.env`
3. Ejecutar: `python src/trading_bot_crew/main.py`
